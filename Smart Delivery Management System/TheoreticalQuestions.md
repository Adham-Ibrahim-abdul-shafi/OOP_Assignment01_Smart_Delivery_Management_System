## Q1  Abstraction

### a) What is Abstraction in Object-Oriented Programming?
- It means allowing the other developer to interact with a class without knowing its implementation details, within the constraints I've set.

---


### b)  Why is abstraction considered one of the four pillars of OOP?
- Because it hides complex implementation details and only exposes the essential features to the other developer.

---

## Q2  Abstract Classes vs. Interfaces 

### a)  What is the difference between an Abstract Class and an Interface?  
- Abstract Class:
    - Uses inheritance, can contain variables, methods, and properties.      
    - A child class can inherit from only one abstract class.
- Interface:
    - Uses implementation, contains methods and properties only (no variables).
    - A class can implement multiple interfaces.

---

### b)  When would you choose an Interface instead of an Abstract Class ?
- when need use many interface in one class or when unrelated classes need to share the same capability or contract


---

### c)  Can a class inherit from multiple abstract classes ?  
- No , a class inherit from one class or one abstract class
### Can it implement multiple interfaces ?             
- Yes
